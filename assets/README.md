# Carpeta Assets

Aquí van los recursos estáticos de la app:

## images/
- Logo de la escuela
- Imágenes de fondo
- Iconos personalizados

## icons/
- Iconos SVG personalizados

Para agregar imágenes:
1. Coloca los archivos aquí
2. Ya están configurados en pubspec.yaml
3. Usa en código: `Image.asset('assets/images/logo.png')`
